# Zoom: отдельное аудио для расшифровки

Исходники действующего Apify actor `gyglem/my-actor-1` (`oJfkaKVvRjus5CYYt`). Его задача `gyglem~my-actor-1-task` используется ночной транскрибацией и Штабом.

Новый интерфейс Zoom: More → Download (N files) → Select files to download. Сборщик снимает выбранные файлы, выбирает только Audio only и нажимает Download (1). Старый интерфейс с прямым скачиванием поддерживается. Поиск аудиоссылки в HTML продолжается, даже если уже найдено видео проигрывателя.

Проверки: `node --test apify/zoom-audio/test/audio-picker.test.js`, `node --check apify/zoom-audio/src/main.js` (из корня amo-export).

Выпуск: загрузить содержимое этой папки в отдельную SOURCE_FILES-версию actor, собрать с тестовой меткой, проверить получение ровно одного файла с audio_url. Только после этого перенести метку latest на проверенную сборку. Тестовые записи и результаты с cookies/подписанными ссылками хранить вне Git. API-ключ берётся из Doppler, не из исходников.

Для проверки всей цепочки запустить workflow zoom-transcribe.yml с полями deal=<ID сделки>, limit=1. Обычный запуск без deal обрабатывает прежнюю очередь; готовые расшифровки повторно не создаются. Проверить ссылку в дпд!I и её появление в ZOOM!M по существующей формуле.
